## Ejecución local

Clona el repositorio y abre `index.html` en un navegador:

```bash
git clone https://github.com/elentrex/mis-proyectos.git
cd mis-proyectos
```

También puedes iniciar un servidor local sencillo:

```bash
python -m http.server
```
